=== STEP-BY-STEP TO PUBLISH ===

1. Authenticate gh CLI (this also sets up git credentials for https push):

   gh auth login --hostname github.com --git-protocol https --web --skip-ssh-key

   - It will print a one-time code and a URL: https://github.com/login/device
   - Open the URL in your browser (on any machine), log in with your GitHub account, and paste the code.
   - Latest known good code (as of the last attempt): 490E-4F53
   - Older codes you may have seen (2DA7-CFBD, C8BB-4C22, ...) are stale — always use the most recent one printed by the login command.

   After success you should see something like:
     github.com
     ✓ Logged in to github.com account pescadordegoiaba

2. Push the real source (this is the big one — first push of the full kernel tree):

   git remote -v   # should show the correct origin (fix below if needed)
   git push -u origin main --force
   git push --tags --force

   This will take time and bandwidth (full source + git objects). Be patient.

3. After the push succeeds, polish the repository:

   gh repo edit pescadordegoiaba/linux-zen-sukisu \
     --description "Linux ZEN kernel source fork with SukiSU-Ultra + SUSFS fully integrated and adapted (x86_64 desktop + Waydroid ready)" \
     --homepage "https://github.com/SukiSU-Ultra/SukiSU-Ultra" \
     --add-topic linux-kernel,zen-kernel,sukisu,kernelsu,susfs,root,waydroid,android,x86_64

   # Optional: create a release pointing at the tag
   gh release create v7.0.9.zen1-sukisu \
     --title "v7.0.9.zen1-sukisu" \
     --notes "Full source snapshot of linux-zen 7.0.9.zen1 with SukiSU-Ultra + SUSFS adapted. See the README inside the tree for build instructions."

4. (Optional) Clean up this file from history later:
   git rm PUSH_INSTRUCTIONS.txt
   git commit -m "docs: remove push instructions (now published)"
   git push

=== Troubleshooting ===

- If "git remote -v" looks weird (e.g. "originhttps..."), run:
    git remote remove origin
    git remote add origin https://github.com/pescadordegoiaba/linux-zen-sukisu.git

- The remote is already correctly set in .git/config. The display quirk above does not affect pushes.

- To verify the tree before pushing:
    git log --oneline -1
    git tag -l
    ls drivers/kernelsu/ fs/susfs.c packaging/arch/

- After push, anyone can build with:
    git clone --branch v7.0.9.zen1-sukisu https://github.com/pescadordegoiaba/linux-zen-sukisu.git
    cd linux-zen-sukisu
    git submodule update --init --recursive   # get SukiSU-Ultra manager source
    cp config.x86_64 .config
    make LLVM=1 LLVM_IAS=1 -j$(nproc)
